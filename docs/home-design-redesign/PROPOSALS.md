# 博客首页改造方案（4 选 1）

> 结论先行：**当前首页单调的根因不是"不好看"，而是"只有一种节奏"**——从上到下全是同一套「封面 + 标题 + 摘要」卡片，没有主次、没有色彩分区、没有侧栏、没有排版锚点。四个方案分别用不同手段打破它。

---

## 一、现状拆解（`app/components/blog/BlogHome.vue`）

| 区块 | 现状 | 问题 |
|---|---|---|
| Hero | 最新文章大卡 | 与下方卡片**同构**，只是大了一号，主次没拉开 |
| 精选文章 | 2 列 × 2，`ArticleCover variant=card` | 连续 4 张同规格卡 → 视觉疲劳的元凶 |
| 底部三栏 | 分类 / 标签 / 关于 | 纯文字，无视觉重量，像"页脚注释" |
| 全局 | 白底 + 灰字 + 品牌色点缀，`container` 居中 1200px | 全篇单一明度、单一节奏 |

**一句话**：信息层级真实存在（Hero > 精选 > 元信息），但**视觉层级没跟上**——所以眼睛扫过去是一片"平"。

---

## 二、四个方案

预览入口：`docs/home-design-redesign/index.html`（四宫格 iframe，可对比）  
单独文件：`style-a-magazine.html` / `style-b-dark.html` / `style-c-colorblocks.html` / `style-d-typographic.html`

### A · 杂志分栏（Magazine Split）
- **版面**：左 1.6fr 正文流 + 右 1fr 侧栏（热读排行 / 分类 / 标签 / 订阅）。
- **手段**：精选文章从"卡片网格"改成**横向列表行**（150px 缩略图 + 标题 + 摘要），单位密度更高、阅读感更强；Hero 用衬线大标题（46px）。
- **配色**：白底 + 品牌色 + 大量细线分隔，靠**线**而非**卡**做结构。
- **字体**：标题 `Georgia/宋体`，正文无衬线。
- **适配**：最像传统博客/专栏，SEO 友好，侧栏可挂广告/订阅。

### B · 暗色编辑部（Dark Editorial）
- **版面**：全宽 Hero 海报 + 3 列卡片 + 底部大数字分类块。
- **手段**：深墨底（`#0b0d12`）+ 品牌色霓虹高亮，Hero 56px 巨型标题，卡片 hover 上浮发光。
- **配色**：深底 + 玻璃拟态导航 + 渐变封面。
- **字体**：无衬线，宽字距英文小标 + 紧字距中文大标。
- **风险**：暗色对中文长文阅读不友好（适合首页，进详情页建议切回浅色）。

### C · 分类色块流（Color-blocked Feed）
- **版面**：顶部**分类 Tab** + 左右分栏置顶大卡 + 2 列带色条卡片流。
- **手段**：**每个分类一个主题色**（技术蓝 / 生活绿 / 随想橙 / 笔记紫），卡片顶部 5px 色条 + 封面渐变同色。
- **配色**：多色，但每屏最多 3 色，靠色彩建立"栏目感"。
- **字体**：无衬线，分类用小号粗体大字距。
- **适配**：最"内容站/资讯站"，栏目多、更新频繁时辨识度最高。

### D · 瑞士极简大字（Swiss Typographic）
- **版面**：左侧标签 + 巨型标题引言 → **编号目录式**文章列表（01/02/03…）→ 底部数据条。
- **手段**：**完全不用封面图**，靠 26px 标题、超细分隔线、负字距（-2.5px）撑气场；hover 整行右移 + 序号变色。
- **配色**：黑白 + 单点强调色（示例用玫红 `#e11d48`，可换成品牌色）。
- **字体**：Helvetica 系，全大写英文导航。
- **适配**：最"高级感"，但对内容质量要求高——没有图兜底，标题不行就露怯；不适合以图为主的站。

## 三、对比与选择

| 维度 | A 杂志分栏 | B 暗色编辑部 | C 分类色块流 | D 瑞士极简 |
|---|---|---|---|---|
| 解决"单调"的手法 | 版面分区 | 明暗对比 | 色彩分区 | 字排版式 |
| 视觉冲击 | 中 | 高 | 中高 | 中 |
| 中文长文友好 | 高 | 低 | 中高 | 高 |
| 内容密度 | 高 | 中 | 中 | 高 |
| 图片依赖 | 中 | 高 | 高 | **无** |
| 改造工作量 | 中 | 中 | 中 | **小** |
| 与现有 `ArticleCover` 海报 | 兼容 | 兼容（换暗色主题） | 需扩展分类色映射 | **可弃用封面** |

**推荐**：
- 想要**稳、耐看、专业** → **A 杂志分栏**（粉丝/专栏型博客首选，投入产出比最高）。
- 想**眼前一亮、做产品门面** → **C 分类色块流**（你后面要接单做垂直内容站，这套"栏目色"最容易做出差异化）。
- 懒得动结构、只要"不再单调" → **D**（改一个组件即可，风险最低）。

---

## 四、落地路径（选定后）

改造集中在 3 个文件，不影响后端：
1. `app/components/blog/BlogHome.vue` —— 版面重排（主要工作量）。
2. `app/components/ArticleCover.vue` —— A/B 几乎不用改；C 需新增"分类色映射"；D 首页可不用它。
3. `app/assets/css/main.css` + `tailwind.config.js` —— 栅格/字体/配色 token 调整。

新增数据依赖（如侧栏"热读排行"）：复用现有 `/api/articles`（按 `viewCount` 排序）即可，**无需后端改动**。

> 注意：方案 C 的"分类色"和方案 A/D 的强调色都应走 **品牌色变量**（`useBrandTheme` / `--brand`），否则会破坏"一套代码换肤换名"的产品化目标。
