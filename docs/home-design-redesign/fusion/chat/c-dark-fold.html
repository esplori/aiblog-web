多智能体编排到底该怎么选？Supervisor 还是 Handoff？
已深度思考 12 秒
用户问的是选型。先区分两个模式的控制权归属：Supervisor 是中心化调度，Handoff 是去中心化移交。
关键变量：任务是否可预先分解、是否需要共享状态、失败时谁来兜底。
结论：能画成流程图 → Supervisor；轮次不固定、靠对话推进 → Handoff。

一句话区分：Supervisor 是"主管派活"，Handoff 是"同事转交"。

  • Supervisor——一个中心 Agent 持有全局状态，按计划调用子 Agent。可控、可观测、好调试。适合流程明确的场景。
  • Handoff——每个 Agent 都能把控制权交给下一个。灵活，但状态容易丢，调试像追接力棒。

实践里最稳的是混合：顶层用 Supervisor 控流程，节点内部用 Handoff 处理开放式对话。

orchestrator.py
# 顶层：Supervisor 控流程
async def run(task):
    plan = await supervisor.plan(task)
    for step in plan:
        # 节点内部：Handoff 处理开放式对话
        await worker.handoff(step, shared_state)
