帮我看看，为什么我的 Nuxt 3 页面首屏加载这么慢？

首屏慢通常来自三个地方，按影响从大到小排：

  • 服务端渲染阻塞——useAsyncData 里的请求是串行的，接口一慢整页就等。
  • 水合（hydration）成本——客户端要重新跑一遍组件树，包越大越慢。
  • 资源体积——图片没做响应式，JS chunk 没拆分。

先加一段配置，把「哪些请求必须等服务端」和「哪些可以等客户端」分开：

nuxt.config.ts
export default defineNuxtConfig({
  // 让慢接口不阻塞首屏
  routeRules: {
    '/articles/**': { swr: 60 },
    '/api/**': { cache: { maxAge: 60 } }
  },
  experimental: { payloadExtraction: true }
})

改完用 nuxi analyze 看看包体积，重点砍掉没用的依赖。
