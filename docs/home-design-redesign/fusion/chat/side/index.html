对话布局 + 侧栏 · D / E / F

在 ChatGPT 式布局上再叠一个右侧栏。对应三种真实产品形态：引用来源 / 产物画布 / 上下文管理。
D · 右侧引用栏
Perplexity 式。正文里的 [1][2] 角标 ↔ 右栏来源卡一一对应。顶部「来源 5」按钮可开合。
只读信息编号角标可开关
新窗口打开 ↗
E · 右侧画布栏
Claude Artifacts 式。对话被压窄到 400px，右侧让给「产物」。顶部切 预览 / 代码 两个 tab。
可交互产物预览/代码切换对话让位
新窗口打开 ↗
F · 右侧上下文栏
项目知识库式。右栏是文件树（可勾选挂载）+ 底部 token 占用进度条 12.4k/128k。
文件树可勾选token 计量
新窗口打开 ↗
共同结构：左侧会话栏 + 中间对话流 + 右侧新增栏，右栏都能关闭（关闭后中间内容自动变宽）。
三案的区别在「右栏装什么」：D 装只读的证据、E 装可交互的成品、F 装可管理的资源。
可以试：D 点右上「来源 5」收起右栏；E 点「代码」tab 切换；F 勾选/取消文件、点右上「上下文 4」收起。
