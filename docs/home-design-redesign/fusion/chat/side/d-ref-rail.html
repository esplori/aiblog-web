Nuxt 3 首屏加载慢，主要卡在哪？

首屏慢主要卡在服务端渲染的等待上。默认情况下 useAsyncData 的请求是串行的，任何一个接口慢，整页 HTML 就出不来。

其次是水合成本——客户端要把整棵组件树再跑一遍，包越大越慢。如果你用了很多只在浏览器跑的库，水合会明显拖后腿。

最后是资源体积：图片没做响应式、代码没分块，都会压在首屏。Nuxt 自带的 payload extraction 能把数据从 JS 里挪出来，直接省一截。

Pylox 也可能会犯错。请核查重要信息。
