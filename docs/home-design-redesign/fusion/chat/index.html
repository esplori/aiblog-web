三案共同骨架：侧栏 260px（会话按 今天/昨天/更早 分组）+ 消息区最大宽 768px 居中 + 底部胶囊输入框（圆角 26px）。
ChatGPT 风格的三个记忆点：① 用户消息是灰气泡、助手消息没有气泡；② 输入框永远是圆角胶囊、右侧一个黑色圆形发送键；③ 全屏只用黑白灰，几乎没有品牌色。
可以试：B 里点代码块右上「复制」（会变绿勾）；C 里点侧栏图标收起侧栏，左上角会出现展开按钮。
