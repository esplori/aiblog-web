工作台版（v2）· 设计稿

把首页从「内容流」改成「应用工作台」：左边是模块化侧边栏，右边是功能区；博客与 AI 广场 成为同级模块，切模块时外壳不变、只有功能区换。
视觉与交互基线对着当前公开规范做：WCAG 2.2、ARIA APG、现代 CSS（container queries / :has() / color-mix）与 Core Web Vitals(INP)。

浅/深双主题

这一版改了什么

  • 信息架构：顶部导航 → 左侧模块栏（模块 = 一级，模块内 = 二级）
  • 首页内容：Hero + 文章网格 → Bento 工作台（继续阅读 / KPI / 待办 / 热门条目）
  • 视觉：圆角 16→12，阴影只在浮层，密度提高，细边框划结构
  • 交互：⌘K 命令面板、可折叠图标轨、URL 即状态、乐观更新
  • 主题：令牌化到浅/深双套（不反相，语义色分别校准）

这一版没动的

  • 品牌体系：--color-brand + 11 档 brand 色阶，换肤与多客户克隆照旧
  • 内容页：/articles、/post/[uuid] 仍是 SSR 长文版式（阅读体验不动）
  • 条目的 5 类 / 4 档风险 / 兼容性矩阵 / 实测报告（v1 已确认的部分）
  • 后台沿用现有侧边栏 + 菜单驱动权限
