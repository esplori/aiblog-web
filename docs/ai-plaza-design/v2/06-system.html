设计系统 v2 与规范对照

工作台版不是「换个皮」：它把首页从内容流变成了应用外壳，因此必须显式说明交互与无障碍基线。下面每一条都对着可验证的公开规范。

1. 令牌：浅色 / 暗色双套

暗色不是「反相」，而是独立的表面层级（bg → surface → surface-2 → surface-3）。品牌色与语义色在两个主题下都保持可辨识度。

2. 间距、圆角、字阶

间距一律 8 的倍数（4/8/12/16/24/32）。圆角比 v1 更小：卡片 12、控件 8/6 —— 工作台的元素更密，大圆角会显得松散。

3. 侧边栏两态 + 容器查询

5. 规范对照清单

下面每条都在工作台里有落点，实施时按此验收。

✓WCAG 2.2 §2.5.8 触控目标 ≥ 24×24（移动端按 44 执行）
✓WCAG 2.2 §2.4.11 焦点不被粘性顶栏遮挡 → 锚点滚动加 scroll-margin-top
✓WCAG 2.2 §1.4.3 正文对比 ≥ 4.5:1，暗色下语义色提亮
✓WCAG 2.3.3 尊重 prefers-reduced-motion，减弱动效时禁用过渡
✓WCAG 2.4.1 每页首个可聚焦元素是「跳到主内容」
✓ARIA APG 顶部模块切换用 tabs 模式；⌘K 面板用 dialog + listbox，Esc 关闭、方向键选择
✓ARIA APG 侧边栏折叠用 disclosure；当前项用 aria-current 而不是只靠颜色
✓Core Web Vitals 交互响应看 INP：乐观更新 + 骨架屏，避免点击后整屏空白
✓现代 CSS container queries / :has() / color-mix() / dvh / focus-visible
✓URL 即状态 筛选与分页写进 query，可分享可回退；不用纯前端内存态

参考：WCAG 2.2 (w3.org/TR/WCAG22) · ARIA APG (w3.org/WAI/ARIA/apg) · MDN CSS Container Queries / :has() / color-mix() · web.dev INP

6. 工作台 vs 传统博客首页

维度 传统首页（v1 / 现状） 工作台（v2）
首页目的 展示内容，给搜索引擎和陌生访客 回到站点继续干活，给自己和常来的人
信息密度 低（大图 + 大标题） 高（行式列表 + KPI + 待办）
模块切换 顶部导航跳页 侧边栏一级模块 + 模块内二级
SEO 风险 低 较高 → 必须保留 /articles、/post/xxx 的 SSR 与站内链接

这是本稿与 boss 最需要确认的一点：见 DESIGN-v2.md §6「SEO 与访客路径」
