真实浏览器里的点击、截图与断言。让「改完自己验一遍」从口头承诺变成可回放的自动动作。

该条目会在本机执行命令并访问网络

playwright-mcp 会启动真实浏览器进程、读写本地缓存并访问你打开的任意网址。请仅在你信任的仓库中启用，并优先使用隔离的浏览器 profile。本站不代管、不审计第三方代码。

安装 选你的客户端，复制即可

~/.pi/settings.json
{ "mcpServers": { "playwright": { "command": "npx", "args": ["-y", "@playwright/mcp@latest", "--isolated"], "env": { "PLAYWRIGHT_BROWSERS_PATH": "~/.cache/ms-playwright" } } } }
要求 Node ≥ 20；首次运行会自动下载浏览器内核（约 130 MB）。pi 需在 permissions.network 中放开 playwright 域名。

能力说明

把浏览器作为工具交给模型：导航、点击、输入、截图、读取 DOM 与网络响应。典型用途不是「写测试」，而是改完自己验一遍——模型在提交前先跑一次真实页面，肉眼可见地确认没写错选择器。

适合的场景

  • 前端改动的自检：截图比对 + 控制台报错捕获
  • 爬取需要登录态的页面（用持久化 profile）
  • 把「复现步骤」变成可回放的脚本片段

不适合的场景

  • 规模化压测（这不是压测工具）
  • 生产环境带真实账号的自动化（有误操作风险）
实测建议：始终加 --isolated，否则会污染你日常的浏览器 profile，登录态混淆后很难排查。

基本动作都通，但默认拿不到外网请求：pi 的 permissions 默认只放行已声明的域名，浏览器内跳转到新域名会被拦。手动把目标域名加进白名单后正常。另外 --isolated 必须加。
