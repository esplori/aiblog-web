# Dashboard 设计

> 版本 v1（2026-10-25）：从「零代码用提示词做高级 dashboard」的方法沉淀。
> 平台注入版是精简稿 `SKILL.inject.md`（约 1.7k 字符，受 maxCharsPerSkill 限制）；本文是全量版，改动后需同步精简稿并重新入库。

当用户要设计后台 / 看板 / 数据大屏，或用提示词让 AI 生成 dashboard 界面时使用。
本技能给的是**提示词工程 + 设计判断**：把模糊需求翻译成 AI 能精准执行的规范，以及判断生成结果为什么像模板、该怎么改。
不负责真出图（没有图像生成模型），产出的是提示词、token 系统、评审意见。

## 触发条件

- 「帮我设计一个 dashboard / 后台 / 看板 / 大屏」→ 先走「第一段：定方向」
- 「怎么写提示词让 AI 做出 XX 风格的界面」→ 走「风格库」+「提示词骨架」
- 生成结果偏模板 / 不好看 / 太空 → 走「评审与修正词」
- 只问侧边栏、菜单、交互布局 → 直接跳到对应小节

## 第一段：先定方向，别急着出提示词

任何非琐碎任务，先给一份四元组让用户确认（风格 / 布局 / 视觉 / 场景），再写完整提示词。
跳过这步直接生成，十次有九次是在重调风格。

```
风格方向：极简商务 / 清爽明亮 / 暗黑科技 / 高饱和撞色（选一，不混用）
布局结构：响应式？顶部导航还是侧边栏？卡片与图表各占什么位置？
视觉细节：底色 + 卡片层级 + 圆角 + 阴影 + 强调色（给 hex 和 px，不给形容词）
业务场景：企业后台 / 个人工具 / 运维监控 / 创意团队；数据类型（如「销售 KPI + 用户增长曲线」）
```

四元组就是后面所有产出的唯一事实来源。

## 风格库（四种，各有适用场景）

| 风格 | 适用 | 提示词关键词 | 反面 |
|---|---|---|---|
| 极简商务 | 企业后台、面向管理者 | 留白、卡片层级、专业稳重、顶部导航、KPI 卡片 + 趋势图 | 装饰性插画、多强调色 |
| 清爽明亮 | 个人工具、C 端产品 | 浅色底、大圆角、单一高亮色、透气感 | 密集边框、深色重块 |
| 暗黑科技 | 数据分析、运维监控 | 暗色背景、高亮度数据、动态网格、发光描边 | 大面积纯白卡片 |
| 高饱和撞色 | 创意团队、内部工具 | 荧光色 + 纯黑、超大标题、单一亮色 + 黑白底 | 三种以上亮色同时上 |

硬规则：**一个界面只用一种风格**。混搭（暗底 + 浅色卡片 + 荧光绿 + 大圆角）就是模板感的来源。

## 提示词骨架

按「风格 + 布局 + 视觉 + 场景」四段写，每段带数值。

```
【场景】企业销售后台，用户是运营主管，核心任务是监控日活与转化，次要任务是看渠道明细。
【风格】极简商务：留白主导，卡片靠层级而非描边区分，无装饰性图形。
【布局】顶部导航（高 56px，透明底），下方 12 栅格；首屏 4 个 KPI 卡片（等宽，间距 24px）+ 1 个趋势折线图占 8 栅格；
下滚为渠道明细表格（表头吸顶）。
【视觉】底色 #F7F8FA，卡片 #FFFFFF 圆角 16px、阴影 0 2px 8px rgba(0,0,0,0.04)；
主色 #2563EB 只用于选中态与主曲线；数字用等宽字体，KPI 字号 32/600，标签 12/500 灰 #6B7280；
正文 14/400，间距系统 8 的倍数。
【约束】不要渐变、不要玻璃拟态、不要三列等宽卡片栅格当主体、不要每个元素都投影。
```

写法要求：
- **数值量化**：模糊 12px、圆角 26px、组间距 32px 这类参数必须写，形容词不算
- **术语前置**：先用术语锚定效果（毛玻璃卡片、共享选中态、透明导航、液态高亮），再补参数
- **单点强调**：说明「哪个元素是唯一强调色落点」，否则 AI 会到处上色
- **分块验证**：先要静态布局，再迭代交互（「先出玻璃卡片 + 月份条静态版，再补点击联动」）

## Dashboard 六要素（评审用这个清单）

1. **场景与数据优先级**：谁看、看什么、先看什么。核心 KPI 放顶部，次要信息下沉，禁止信息堆砌。
2. **布局与层级**：网格建立秩序，用对齐 / 留白 / 分组分区；首屏只放重点，下滚放详情。
3. **配色**：主 60% / 辅 30% / 强调 10%；强调色必须落在关键数据上；风格匹配场景。
4. **组件与可视化**：趋势用折线、占比用饼/环、对比用柱；统一圆角与阴影；数字带单位、可简化（1.2k）；不堆图表。
5. **交互与响应式**：筛选、钻取、刷新、下钻详情；移动端单列 + 折叠菜单。
6. **规范与性能**：统一字体 / 图标 / 间距；长列表虚拟滚动，避免数据刷新时卡顿。

## 侧边栏 / 菜单

### 三种视觉质感（任选其一，别叠）

- **悬浮面板**：脱离屏幕边缘留 16px 边距，圆角 20px，低透明度柔和投影，背景透出页面底色
- **深色重底**：浅色主区 + 高对比深色栏；常规项低饱和浅灰，激活项强调色，视觉重心集中在栏上
- **磨砂玻璃**：`rgba(255,255,255,0.15)` + blur 12–24px + 1px 亮边，适配渐变 / 图片背景

### 信息架构

- 双层导航：左 72px 图标轨切模块，右 240px 面板展二级菜单（数据密集型后台首选）
- 分组留白：组间距 32px，组名 11px 大写灰字；底部固定用户区 / 用量，中间列表独立滚动
- 基础规范：图标 + 文字 220–260px，纯图标 72px；图标与文字间距 8–12px；移动端默认折叠

### 六种菜单摆放

| 方案 | 做法 | 适用 |
|---|---|---|
| 透明顶栏 | 无底色无分隔线，选中项用半透明白圆角底 | 首屏有大图 / 渐变背景 |
| 右侧竖轨 | 主菜单固定右侧收为窄图标轨，当前项深色圆角底 | 内容区需整块展示的看板 |
| 选中展开文字 | 默认仅图标，选中项展开为带文字长条（弹性动画） | 顶栏入口多、文字放不下 |
| 图标轨 + 大标题 | 侧栏仅图标，页面名做大标题放左上角（旁附范围选择器） | 页面少的工具类后台 |
| 图标轨 + 悬停提示 | 仅图标，hover 弹文字提示，图标间细线分组 | 功能多、屏幕窄 |
| 菜单旁快捷操作 | 高频动作（新建 / 导出）在菜单旁单列圆形按钮，关键操作亮色 | 需随时执行动作的后台 |

## 六种交互布局

1. **可拖拽重排网格**：模块拖动，其他模块平滑让位，松手吸附；用户自定义视图，需响应式。
2. **模块就地放大**：点击图表原位放大为主视图，原区域缩为底部缩略条，点缩略图切换或关闭；用于数据钻取，动画必须流畅。
3. **顶部筛选 + 全区联动**：筛选器固定顶部，切换时数字滚动过渡、图表平滑更新，不整页刷新。
4. **多图表悬停联动**：hover 某数据点，其他图表同维度同步高亮、无关数据变淡加参考线；前提是维度（如时间轴）一致。
5. **指标区滚动吸顶**：KPI 区随滚动收缩为单行固定顶栏，回滚还原；过渡要跟滚动进度关联，避免抖动。
6. **列表 + 详情抽屉**：点行右侧划出详情，列表压窄留左，支持键盘上下切换，当前行保持高亮。

基础布局三选一：垂直堆叠（数据少，需配吸顶 / 锚点）、多列固定（复杂系统，注意列宽）、自由画布（大屏，防重叠）。

## 玻璃点阵布局（可直接复制的模板）

```
实现浅灰底「玻璃点阵 Dashboard」：毛玻璃卡片（rgba(255,255,255,0.15)、blur 12px、1px 白边、
26px 圆角、14px 内边距、subtle box-shadow）承载点阵 KPI（等宽像素字体如 Geist Mono，
#89FF00 高亮，数据更新时数字逐位翻滚 15 帧/秒、无缓动）；顶部月份条串联数据，
点击月份同步更新所有点阵，点击单个指标浮出该指标趋势曲线；共享选中态双向绑定、无冲突；
整体底 #F8F9FA，文字 #333；标题 600 / 正文 400，响应式适配 1920px 宽屏。
```

拆四段写：核心布局（结构与联动）→ 玻璃风格（参数）→ 点阵样式（字体 / 颜色 / 动效）→ UI 规范（间距 / 字重 / 断点）。

## 评审与修正

按「谁会注意到」排序：读不清（对比度 / 字号 / 行宽）> 看不懂（层级 / 主次）> 不成体系（间距圆角灰阶随手给）> 不像这个产品。每条给位置、问题、一句怎么改。

生成结果偏模板时，按症状加修正词：

- 到处是灰块 → 「减少灰色块，卡片靠留白和层级区分，仅保留一层阴影」
- 没有重点 → 「强化品牌色，只让主图表和首要 KPI 使用强调色，其余降为中性灰」
- 元素都浮着 → 「去掉所有投影，仅弹层与悬浮卡片保留阴影」
- 太挤 / 太散 → 「统一间距为 8 的倍数，模块间距 24，卡片内边距 20」
- 圆角混乱 → 「所有卡片圆角 16，按钮 10，标签胶囊 999，不得混用」
- 图表像默认库 → 「折线去掉网格线，仅保留水平参考线，线宽 2，端点圆角，颜色用主色」

## 术语表（对齐 AI 用词，减少返工）

透明导航 transparent nav / 液态高亮 liquid highlight / 毛玻璃 frosted glass / 共享选中态 shared selected state /
点阵数字 dot-matrix digits / 逐位翻滚 odometer roll / 图标轨 icon rail / 吸顶 sticky / 抽屉 drawer / 就地放大 in-place zoom。

同一份提示词里术语必须前后一致，混用会让 AI 每段都重新猜。

### 玻璃渐变型（Clime 风，2026-10 定稿）

整屏固定渐变背景（雾蓝 → 淡紫 → 粉 → 桃），卡片半透明磨砂（`rgba(255,255,255,.58)` + blur 20 + 1px 亮边 + 圆角 26），
KPI 用 2–3 张低饱和渐变实心卡（绿/橙/粉辐射）承担视觉焦点，其余卡保持玻璃白；控件全部胶囊化。
要点：实心卡上的数字用深墨而非白字（白字对比只有 3.5:1）；系列色同屏 ≤5 个；表格页保持白底，别铺渐变。
样例与可复用 CSS：aiblog-web `design-prototypes/admin-clime/`、`app/assets/css/admin-themes/clime-soft.css`。

## 注意事项

- 不能生成图片；要插画、产品渲染图直说做不到。
- 别信「好看一点」「高级感」这类指令，先转成可量化的规范。
- 参数给了就守住，不要在一份提示词里出现两套圆角或两套间距。
- 生成后先看首屏：首屏缺焦点就是布局问题，不是配色问题。
- 结论不确定就说不确定，别为模板感编理由。
