# 后台「Clime 浅色」风格稿

来源：2026-10-25 设计迭代定稿版（aiblog 后台数据总览）。

## 文件
- `full-clime2.html` 原型入口（直接浏览器打开，数据为假数据）
- `clime2.css` 风格层（配色 + 玻璃卡 + 胶囊控件 + 细节）
- `v3.css` / `style.css` 结构与组件层
- `v3.js` 图表与交互（手写 SVG，无第三方图表库依赖）
- 生产主题文件：`app/assets/css/admin-themes/clime-soft.css`

## 风格要点（复用时的最小集）
1. 背景：整屏固定渐变（#D9DFF7 → #E7D8F1 → #F8DEDD → #FCE8D3），滚动不跟随
2. 卡片：`rgba(255,255,255,.58)` + `backdrop-filter: blur(20px) saturate(150%)` + 1px 半透明亮边 + 圆角 26 + 内高光
3. 高亮卡：三张低饱和渐变实心（绿 #B8E39A / 橙 #FFD19A / 粉辐射 #FFC1A6），数字深墨 #1E2A18，字距 -0.035em
4. 控件：搜索/按钮/分段全部胶囊化，高 34px；筛选胶囊组高 36px，第一颗 #FBEE96 高亮
5. 系列色：绿 #6FBA5A、橙 #F2A65C、玫 #E084A8、蓝 #6E8FDB、紫 #A99BD6（同屏 ≤5 色）
6. 动效：卡片 hover 上浮 2px + 阴影 180ms；条形 7px 全圆角

## 注意
- 深色文字在浅渐变卡上的对比 ≈ 12:1；若改回白字会掉到 3.5:1，只能用于 ≥24px 大字号
- 全屏渐变不适合长时间盯数据，概览/汇报更好用；表格页保持白底
